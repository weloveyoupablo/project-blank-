PHONE-ONLY GITHUB PAGES DEPLOY
1. Create a public GitHub repository (example: blank-app).
2. Upload every file in this folder to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select branch: main, folder: /(root), then Save.
5. Wait for GitHub Pages to publish.
6. Open the published https://...github.io/... address in Safari.
7. Tap Share > Add to Home Screen.
